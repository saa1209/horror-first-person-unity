# Horror FPS — Asset Scripts

Pure C# scripts designed to drop into a Unity project's `Assets` folder.

## Quick setup

1. Open Unity `6000.0 LTS` or `2022.3 LTS`.
2. Copy the `Scripts` folder into `Assets/Scripts`.
3. Create an empty **GameObject** and add `HorrorGameManager`.
4. Configure player references and story sequences in the inspector.
5. Generate a character by combining a `CharacterController` with `FirstPersonController`.

The scripts use only built-in Unity APIs and do not require a package install.
